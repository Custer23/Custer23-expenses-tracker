# Custer23 Expenses Tracker

This repository will contain a full-stack expenses tracking application (backend + frontend).

Planned features:
- Backend: Node.js + Express + Prisma + PostgreSQL
- Frontend: React + Vite + TypeScript
- User authentication (email/password + JWT)
- CSV import/export
- Charts and summaries
- Categories, Budgets, Recurring expenses
- Docker + docker-compose for local development
- GitHub Actions CI

I will create the initial project files and branches next.
